# 🌊 Algae Bloom Tracker

**Algae Bloom Tracker** is a React Native mobile application that uses **Gemini AI, crowdsourced observations, and location-based mapping** to help monitor potential algae blooms in bodies of water.

Users can take or upload a photo of a water body, and Gemini AI analyzes the image to provide information such as **bloom detection, severity level, bloom type, confidence score, and visual observations**. Users can review and edit the AI-generated results before submitting the observation.

Each report is saved with its **location, photo, timestamp, AI analysis, and user-provided information**. Reports are then displayed on an interactive map, allowing users to view potential algae bloom locations and inspect individual reports.

As more people contribute observations to the same area, the application can use the collected data to identify **potential hotspots, monitor changes in severity, and improve the reliability of environmental observations**.

### Core Technologies

* **React Native + Expo** — Mobile application
* **Gemini AI** — Image-based algae bloom analysis
* **Firebase Authentication** — User accounts
* **Firebase Firestore** — Observation data
* **Cloudinary** — Image storage and delivery
* **Maps API** — Geographic visualization and bloom mapping
